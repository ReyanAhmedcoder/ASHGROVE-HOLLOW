# Ashgrove Hollow

A short, browser-based horror exploration game. The experience is built with plain HTML, CSS, and JavaScript; it has no build step or package dependencies.

## Run

Open `index.html` in a modern browser. The game can also be served from this directory with any static file server.

## Project files

- `index.html` defines the game interface and loads `style.css` and `script.js`.
- `style.css` provides the layout, HUD, overlays, and atmospheric effects.
- `script.js` controls scenes, hotspots, inventory, choices, audio stingers, and endings.
